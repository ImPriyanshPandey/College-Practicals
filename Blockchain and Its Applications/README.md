# 📁 Blockchain and Its Applications

*Cryptography, hashing, and blockchain fundamentals in Python*

A progression from core cryptographic building blocks (hashing, digital signatures, RSA) up to actually building and deploying a working blockchain - including a Hyperledger Fabric + Docker deployment. This was one of the more genuinely interesting subjects in the degree, not just coursework to clear.

## 🧪 What's in this folder

| # | Practical | What it covers |
|---|-----------|-----------------|
| 1 | Message Digest SHA256 | Generating and verifying SHA-256 message digests |
| 2 | Encrypt Decrypt SHA256 | Encryption/decryption workflow using SHA-256 |
| 3 | Chain of nodes using linked list | Implementing a blockchain's core structure as a linked list |
| 4 | RSA Cryptographic Algorithm | Public-key encryption/decryption using RSA |
| 5 | Blockchain using Proof of Work (PoW) | Implementing PoW consensus for block validation |
| 6 | Sending of Digitally Signed Document | Digital signature creation and verification for document integrity |
| 7 | Hash Table with n buckets and insert the keys | Hash table implementation with bucket-based collision handling |
| 8 | Blockchain with 5 nodes and hash value of each block | Multi-node blockchain with per-block hashing |
| 9 | Blockchain with 5 nodes and check its validity | Chain validity/tamper-detection across multiple nodes |
| 10 | Flask to deploy blockchain | End-to-end deployment: WSL + Docker + Node.js + Hyperledger Fabric test network, channel creation, chaincode deployment, and transaction invocation via a Flask app |

## 🛠️ Tools & Tech Used

- Python
- Flask
- Hyperledger Fabric
- Docker
- WSL
- Node.js / npm
