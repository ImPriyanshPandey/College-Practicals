# 📁 Basic IT Tools

*MS Office practicals - Word, Excel, and Access*

Foundational productivity-tool practicals covering document formatting, spreadsheet automation, and basic database creation in MS Office. Less about "coding" and more about the office-tooling fluency that ends up mattering a lot in real jobs - reports, data sheets, mail merges.

## 🧪 What's in this folder

| # | Practical | What it covers |
|---|-----------|-----------------|
| 1 | Styling & Formatting | General Word document formatting practice |
| 2 | Margins, Orientation, Border, Sections, Header, Footer | Word page layout controls |
| 3 | Table and Table Options | Creating and formatting tables in Word |
| 4 | Replace, Columns, Index, Thesaurus | Word's find-and-replace, multi-column layout, indexing, and thesaurus tools |
| 5 | Hyperlink, Bibliography, Captions | Cross-referencing and citation tools in Word |
| 6 | Mail Merge + Mail Merge Output | Automating personalised documents from a data source |
| 7 | Workbook | Basic Excel workbook setup |
| 8 | Tables & Charts / Pivot table and chart | Excel data summarisation and visualisation |
| 9 | Macro Book | Automating repetitive Excel tasks with macros |
| 10 | Cell Referencing, protecting workbook | Excel formulas and workbook protection (password-protected file) |
| 11 | New Address | Basic MS Access database |

## 🛠️ Tools & Tech Used

- Microsoft Word
- Microsoft Excel (incl. Macros/VBA)
- Microsoft Access

## 📝 Note

Files are in native Office formats (.docx/.xlsx/.xlsm/.mdb) since these are tool-usage exercises, not code - best viewed by downloading rather than in-browser preview.
